# kr-fin-sentiment

네이버 종목 뉴스를 [KR-FinBert-SC](https://huggingface.co/snunlp/KR-FinBert-SC)로 읽고, 최근 20건을 10점 만점으로 집계한다.

## 실행

Python 3.12 이상과 Poetry가 필요하다. 이 저장소의 잠금 파일은 Python 3.15에서 만들었다.

```bash
poetry install
poetry run python finbert.py
```

종목명이나 6자리 코드를 입력한다. 여러 개면 쉼표로 구분한다. 빈 입력이나 `q`로 종료한다. 처음 실행하면 모델 가중치를 받는다.

HTTP로 보려면

```bash
poetry run uvicorn app:app --host 0.0.0.0 --port 8000
```

`GET /health`는 모델 없이 응답한다. `GET /sentiment?q=삼성전자`는 처음 호출할 때 모델을 읽는다.

## 점수

기사 점수는 `P(긍정) - P(부정)`이다. 범위는 -1에서 1이다.

집계는 반감기 1일이다. 가중치는 여기에 `P(긍정) + P(부정)`을 곱해서, 중립에 가까운 기사는 평균에서 거의 빠진다.

10점 점수는 `(가중평균 + 1) / 2 * 10`이다. 0이 부정, 5가 중립, 10이 긍정이다.

`라벨` 줄은 가중치 없이, 기사마다 확률이 가장 큰 쪽을 센 개수다.

제목과 앞부분 본문에 종목명이 없으면 시황으로 보고 시간 가중치에 0.25를 곱한다. 기사 수는 줄이지 않는다. 한 종목만 조회해도 같고, 같이 조회한 다른 종목과는 무관하다. `삼성`처럼 종목명보다 짧게 적힌 기사는 시황으로 들어갈 수 있다.

계산식만 확인하려면 `poetry run pytest`를 실행한다.
